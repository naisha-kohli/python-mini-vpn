# Mini VPN Project

## 1. What are we building?

We are building a simple VPN prototype using Python and Linux.

The main purpose of this project is to understand how a VPN works internally instead of simply using an existing VPN such as OpenVPN.

We are creating a system where network traffic from a computer can be sent through a VPN tunnel to another computer (the VPN server) before going to the internet.

This is an educational project, not a production-level VPN.

---

## 2. Why are we building it?

When we use a normal VPN application, we usually just select a server and click "Connect."

A lot of things happen in the background:

* Network traffic is redirected.
* A VPN tunnel is created.
* Packets are sent through that tunnel.
* The VPN server receives the traffic.
* The server can forward the traffic to the internet.
* Traffic inside the tunnel can be protected using encryption.

Instead of treating all of this as a black box, we are building a simplified version ourselves so that we can understand each step.

The main goal is:

> Understand what happens to network packets when they travel through a VPN.

---

## 3. What does a VPN actually do?

Without a VPN, the basic flow looks like:

```text
My Computer
     |
     v
My Network / ISP
     |
     v
Internet
     |
     v
Website
```

With a VPN:

```text
My Computer
     |
     v
VPN Tunnel
     |
     v
VPN Server
     |
     v
Internet
     |
     v
Website
```

The VPN server acts as an intermediate point between the client and the internet.

If the VPN server is located in another country, websites may see the public IP address of that server. This is why commercial VPNs can make a connection appear to come from another location.

Our project focuses mainly on understanding and building the tunnel and traffic flow.

# 4. What are we deploying?

We are creating a client-server setup.

```text
                 VPN Tunnel
       ----------------------------

       +-------------+      +-------------+
       | VPN Client  | ---> | VPN Server  |
       |             |      |             |
       |    Kali     |      |    Linux    |
       +-------------+      +------+------+
                                   |
                                   v
                                Internet
```

### VPN Client

The VPN client runs on our Kali machine.

It is responsible for participating in the VPN connection and handling traffic that needs to travel through the tunnel.

### VPN Server

The VPN server runs on another Linux machine or server.

It receives traffic from the VPN client and can forward that traffic toward the internet.
